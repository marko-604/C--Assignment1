\doxysubsection{Detailed Description}
Abstract decorator class for towers. 

Allows additional functionality to be dynamically added to a \doxylink{class_tower}{Tower} by wrapping it. Inherits from \doxylink{class_tower}{Tower} and delegates calls to the base tower.
